MARIDAN — Static Vercel Preview

This package is a static preview version of the WordPress theme. It is intended for viewing the design on Vercel, not for editing content through WordPress. PHP-dependent functionality, WordPress admin features, and server-side enquiry processing are not included in this preview.

Deploy: extract this ZIP, import the extracted folder/repository into Vercel as a static site, use the project root, Framework Preset: Other, Build Command: leave empty, Output Directory: . (or ./).

Pages: /, /about/, /properties/, /contact/
